Ryan OpenClaw

Ryan OpenClaw is Ryan's private personal assistant. It runs on a computer Ryan owns and controls, using the open-source OpenClaw assistant and the gog command-line tool for Google Workspace.

It is not a public service. There is no sign-up, and only Ryan's own Google accounts are connected.

What it does

When Ryan asks, or as part of recurring or proactive tasks he has set up or approved (such as scheduled checks and reminders), the assistant uses Google APIs to work with his own data:

  • Gmail: search, read, organise, draft and send email
  • Google Calendar: view, create and update events
  • Google Drive, Docs and Sheets: find, read, create and edit files
  • Google Contacts: look up and manage contacts
